# Cuelify

Cuelify 是 Windows x64 字幕桌面工具：选择一个本地视频或音频，经语音识别和翻译后导出 UTF-8 SRT。

## 功能

- FFmpeg 音频处理与 Silero VAD 静音优先分片，保留原媒体时间轴。
- ElevenLabs Scribe 词级语音识别，成功分片自动缓存。
- OpenAI-compatible、DeepSeek 官方 API、本地模型推理三种翻译引擎；支持官方模型下载与选择。
- 独立字幕管线：直接翻译、联合分句与翻译、先分句后翻译；可自定义各步骤提示词、参数与字幕显示目标。
- 原译文对照、阶段进度、取消、缓存恢复、单条重翻和译文 SRT 导出。
- 明暗主题；API Key 通过主密码加密保存。

## 运行要求

- Windows 11 x64。
- Windows x64 `ffmpeg.exe` 和 `ffprobe.exe`：加入 PATH，或在界面的「识别与音频高级参数」填写绝对路径。
- ElevenLabs Speech-to-Text API Key；云端翻译另需对应服务的 Key。
- 本地翻译需要完整的 llama.cpp Windows x64 Vulkan 运行包、支持 Vulkan 的 GPU/驱动和指定 GGUF 模型，云端翻译无需本地模型。

发行采用 .NET 10 自包含目录，无需安装开发 SDK。解压整个发行目录后运行 `Cuelify.Desktop.exe`，保留附带的原生 DLL 和资源。FFmpeg、llama.cpp 和 GGUF 不随包提供；Silero ONNX 随包提供。

## 使用

1. 在左侧「设置」配置 ElevenLabs Key 和翻译服务。云端填写地址、模型和翻译 Key；DeepSeek 默认 `https://api.deepseek.com` / `deepseek-flash`。本地选择完整 Vulkan 运行包中的 `llama-server.exe` 或下载运行包，再下载或选择已有模型。选择模型的默认字幕管线，按需创建自定义副本，保存设置；连接测试会真实请求服务或执行本地生成。
2. 返回「工作台」，在「选择文件」步骤选择或拖入一个本地媒体，点击「下一步」检查文件信息。
3. 在「翻译选项」选择本次任务的语言、引擎与字幕管线，点击「开始处理」。本次选择不改变模型默认关联；服务和管线设置可从此步骤直接进入。
4. 在「生成字幕」查看进度和原译文。处理中可以切换到设置或日志页面，任务会继续运行；相关参数暂时不可修改。取消或部分失败后可继续处理，复用成功结果。
5. 全部译文完成后导出 SRT，选中字幕可定向重翻。已完成的任务使用启动时的配置；后续修改设置不会影响其导出或单条重翻。调整任务选项后重新处理，可生成另一种语言或风格的结果。

识别会上传音频，云端翻译会发送原文及上下文，可能产生费用；失败重试和定向重翻也可能再次计费。相同输入与识别参数复用 ASR 缓存，更换翻译配置不会清空已完成的识别结果。部分失败时保留成功译文，完整 SRT 导出要求所有条目有效。

### 本地模型

预置以下官方 GGUF，默认选择第一项：

| 模型 | 量化 | 官方来源 |
| --- | --- | --- |
| Hy-MT2-1.8B | Q6_K | [腾讯](https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF) |
| Hy-MT2-7B | Q4_K_M | [腾讯](https://huggingface.co/tencent/Hy-MT2-7B-GGUF) |
| Index-Translate-9B | Q4_K_M | [IndexTeam](https://huggingface.co/IndexTeam/Index-Translate-9B-GGUF) |

在「设置 → 翻译服务」选择「本地模型推理」及模型，点击「下载模型」。下载文件和默认模型路径直接位于 `%LOCALAPPDATA%\Cuelify\`，与 `settings.json` 同级；本地文件使用稳定的模型 ID 命名，与官方仓库文件名独立。每次下载动态查询官方当前版本、文件名、大小与可用哈希，不在程序中冻结这些值。下载支持取消和续传，校验通过后才替换正式文件；保存设置后用于新任务。手动选择已有文件只检查路径和可读性，无需联网，也不核对文件名、哈希、架构或量化是否匹配预设。模型能否加载由 llama.cpp 判断，失败详情记录到日志；使用已有模型无需访问 Hugging Face。

llama.cpp 下载动态读取 [官方发布](https://github.com/ggml-org/llama.cpp/releases)中的 Windows x64 Vulkan 包（包括滚动预发布），校验 SHA-256 后解压到 `%LOCALAPPDATA%\Cuelify\llama.cpp\<版本>-<包哈希前缀>\`。下载支持取消和续传；不同版本分别保存，更新不覆盖原任务引用的运行程序。下载成功后保存设置，再点击「测试本地翻译」。手动指定程序需保留它的配套 DLL；程序会检查接口能力和 Vulkan 支持。运行包下载需要访问 GitHub，安装后本地生成无需联网。

「设置 → 字幕管线」独立管理流程，内置三个只读管线，可搜索、新建、复制、编辑或删除自定义管线。线上默认联合分句与翻译，1.8B 默认直接翻译，7B 和 Index 默认先分句后翻译；这些只是默认值，所有模型都能选择三个流程。在翻译服务页修改模型默认关联，在工作台选择本次管线。模型切换不改变编辑草稿，切换未保存草稿时询问保存、放弃或取消。已启动任务保持原配置快照；删除自定义管线后相关模型恢复各自默认值。

管线的步骤提示词、设置与样例预览独立编辑。分句使用原始词 ID，由应用校验连续覆盖并计算时间；联合流程同时生成译文，两步流程随后翻译。第一版所有步骤使用同一个任务模型。翻译步骤可选单条纯文本或批量 ID JSON；联合流程的翻译步骤用于后续定向重翻或修复译文。温度、top_p、top_k、重复惩罚与输出上限可分步骤覆盖，留空沿用服务或模型默认值，参数支持取决于提供商。样例预览不推理，真实任务预览使用实际输入及本地 tokenizer。

本地默认并发 2、云端 4，均可设置 1～8。分句块、前后参考、翻译批次、每行字数、最长时间及阅读速度目标由管线管理。语义分句只在自然候选中选择，不丢词或让模型编造时码；缺少合法切点会明确报错，需增加最长时间或选择直接翻译。本地预算不足时裁剪参考或按合法切点拆小块；翻译批次可拆小，单条超限明确失败。每请求模型上下文默认 4096 token，较大分句块建议增加容量，阶段输出上限不得超过容量一半。直接翻译沿用识别字幕时间；语义流程可在可用静音内延长显示，最终时间冻结后补译/重翻保持不变。每行字数限制最多两行，阅读速度是提示词目标，不能保证所有台词都达到。

模型由 Cuelify 自动启动的 `llama-server` 子进程运行，使用 Vulkan GPU 卸载。服务仅监听本机回环地址，自动分配端口，不弹出终端；首次使用加载模型，同配置后续请求复用已加载模型，关闭应用时结束进程。启动前不读取模型内容计算哈希或解析 GGUF 元数据；缓存通过文件路径、大小及修改时间区分模型版本。无需手动启动服务。点击「测试本地翻译」可验证模型运行，GPU 卸载详情见运行日志。模型、驱动或 GPU 不可用时明确报错，不回退 CPU-only。

## 数据与凭据

新版 settings.json 使用 schema 3，不迁移旧配置；首次读取旧版设置时保存为同目录 settings.previous-*.json，再初始化新版默认值。需要重新配置服务与模型，原有 credentials.json、GGUF、运行包和缓存保留。

非敏感配置和管线存放在 `%LOCALAPPDATA%\Cuelify\settings.json`，ASR、分句/联合阶段和翻译缓存分别位于 `Jobs`、`Pipelines`、`Translations`。缓存含音频、原文和译文，分享前请检查内容。

首次使用时在密钥配置区域点击「设置主密码」，设置主密码，再填写 API 密钥并点击「保存密钥」。每次启动需要解锁一次；语音识别、兼容服务和 DeepSeek 密钥分别保存到应用数据目录下的 `credentials.json`，使用 PBKDF2-SHA256 与 AES-256-GCM 加密，不依赖系统凭据存储，也不读取环境变量。主密码不保存，明文 Key 不进入普通配置或日志。

未设置或未解锁主密码、缺少所需密钥时，工作台会提示原因并禁用下一步或开始处理。本地翻译无需翻译服务密钥，仍需要 ElevenLabs 密钥。手动锁定或退出会清除会话凭证，已有完整字幕仍可导出。可在「设置 → 常规」更换主密码或重置凭证；忘记主密码只能重置并重新填写密钥，普通设置和字幕缓存会保留。

## 从源码运行

安装 `global.json` 指定的 .NET 10 SDK，并准备 FFmpeg/ffprobe。在仓库根目录执行：

```powershell
dotnet restore Cuelify.slnx --locked-mode
dotnet run --project src/Cuelify.Desktop -c Release --no-restore
```

完整文档入口见 [文档索引](docs/README.md)。构建、测试、发布及资源来源见 [开发指南](docs/development.md)，运行问题见 [故障排查](docs/troubleshooting.md)。源码仓库中的后续 Agent 从 [AGENTS.md](AGENTS.md) 和 [Agent 文档索引](docs/agents/README.md) 开始。
