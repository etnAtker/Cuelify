# Cuelify

Cuelify 是 Windows x64 字幕桌面工具：在项目中管理多个本地视频或音频，经语音识别和翻译后导出 UTF-8 SRT。

## 功能

- 项目和媒体任务持久化，项目内顺序处理，也可单独操作一个媒体。
- FFmpeg 音频处理与 Silero VAD 静音优先分片，保留原媒体时间轴。
- ElevenLabs Scribe 词级语音识别，成功分片自动缓存。
- OpenAI-compatible、DeepSeek 官方 API、本地模型推理三种翻译引擎；支持预置模型下载与选择。
- 独立字幕管线：程序分句后翻译、模型分句后翻译；可自定义分句和翻译的提示词、参数与字幕显示目标。
- VAD 分片、ASR、字幕分句和翻译有独立结果；可继续未完成部分、仅重试失败部分或重新执行本步骤。
- 原译文对照、阶段进度、取消、单条/多选重翻、旧版本与当前译文 SRT 导出。
- 明暗主题；API Key 通过主密码加密保存。

## 运行要求

- Windows 11 x64。
- Windows x64 `ffmpeg.exe` 和 `ffprobe.exe`：加入 PATH，或在界面的「识别与音频高级参数」填写绝对路径。
- ElevenLabs Speech-to-Text API Key；云端翻译另需对应服务的 Key。
- 本地翻译需要完整的 llama.cpp Windows x64 Vulkan 运行包、支持 Vulkan 的 GPU/驱动和指定 GGUF 模型，云端翻译无需本地模型。

发行采用 .NET 10 自包含目录，无需安装开发 SDK。解压整个发行目录后运行 `Cuelify.Desktop.exe`，保留附带的原生 DLL 和资源。FFmpeg、llama.cpp 和 GGUF 不随包提供；Silero ONNX 随包提供。

## 使用

1. 在「设置」配置 ElevenLabs Key 和翻译服务。云端填写地址、模型和翻译 Key；本地下载或指定 Vulkan 运行包与模型，保存设置。连接测试会真实请求服务或执行本地生成。在「字幕管线」设置各步骤默认模型。
2. 在「项目」新建或打开项目，通过「添加媒体」或拖放加入多个音视频文件，左侧选择要查看的媒体。
3. 打开项目，选择媒体；在「处理设置」选择管线和语言，在各步骤 Tab 下选择所需模型，点击步骤按钮执行本步骤，或在项目顶部批量顺序处理。
4. 在步骤 Tab 查看分片、原始识别词、分句和结果。每步直接显示开始/继续、失败重试和重新执行按钮；有未处理部分时显示继续，全部处理一轮后有失败项才显示失败重试，两者互斥；重新执行创建新版本。处理中可查看其他媒体或日志，在底部停止；批量处理取消后可继续剩余媒体。
5. 完整结果可导出 SRT，也可选择字幕重新翻译。重新翻译保留分句和时码；重新执行分句或结果会创建新版本。更换管线或将上游历史版本设为当前后，下游自动选取最新匹配版本，没有匹配则显示未开始。模型和参数变更用于下次重新执行，继续与失败重试仍使用该版本快照。

识别会上传音频，云端翻译会发送原文及上下文，可能产生费用；失败重试和定向重翻也可能再次计费。相同输入与识别参数复用 ASR 缓存，更换翻译配置不会清空已完成的识别结果。部分失败时保留成功译文，完整 SRT 导出要求所有条目有效。

### 本地模型

预置以下官方 GGUF，默认选择第一项：

| 模型 | 量化 | 官方来源 |
| --- | --- | --- |
| Hy-MT2-1.8B | Q6_K | [腾讯](https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF) |
| Hy-MT2-7B | Q4_K_M | [腾讯](https://huggingface.co/tencent/Hy-MT2-7B-GGUF) |
| Index-Translate-9B | Q4_K_M | [IndexTeam](https://huggingface.co/IndexTeam/Index-Translate-9B-GGUF) |
| Qwen3.5-9B | Q4_K_M | [Unsloth GGUF](https://huggingface.co/unsloth/Qwen3.5-9B-GGUF)，[Qwen 原模型](https://huggingface.co/Qwen/Qwen3.5-9B) |

Qwen 的 GGUF 由 Unsloth 量化提供。默认关闭思考，采样为 temperature 0.7、top_p 0.8、top_k 20、repeat_penalty 1.0；管线步骤的显式参数优先于模型默认值。可在分句步骤选择 Qwen，在结果步骤选择 Hy；更改选择用于下一次重新执行，不改写已有版本。

在「设置 → 翻译服务」选择「本地模型推理」及模型，点击「下载模型」。下载文件和默认模型路径直接位于 `%LOCALAPPDATA%\Cuelify\`，与 `settings.json` 同级；本地文件使用稳定的模型 ID 命名，与来源仓库文件名独立。每次下载动态查询来源仓库当前版本、文件名、大小与可用哈希，不在程序中冻结这些值。下载支持取消和续传，校验通过后才替换正式文件；保存设置后用于新任务。手动选择已有文件只检查路径和可读性，无需联网，也不核对文件名、哈希、架构或量化是否匹配预设。模型能否加载由 llama.cpp 判断，失败详情记录到日志；使用已有模型无需访问 Hugging Face。

llama.cpp 下载动态读取 [官方发布](https://github.com/ggml-org/llama.cpp/releases)中的 Windows x64 Vulkan 包（包括滚动预发布），校验 SHA-256 后解压到 `%LOCALAPPDATA%\Cuelify\llama.cpp\<版本>-<包哈希前缀>\`。下载支持取消和续传；不同版本分别保存，更新不覆盖原任务引用的运行程序。下载成功后保存设置，再点击「测试本地翻译」。手动指定程序需保留它的配套 DLL；程序会检查接口能力和 Vulkan 支持。运行包下载需要访问 GitHub，安装后本地生成无需联网。

「设置 → 字幕管线」管理两个内置只读流程和自定义流程。默认使用模型分句后翻译，与选择的模型无关。管线的分句与结果步骤可以分别设置默认模型；媒体可在对应步骤覆盖。程序分句不需要模型。媒体处理设置只选择管线和语言，已经运行的版本保留配置快照。

管线始终显示分片、识别词、分句、结果四个步骤。程序分句与模型分句输出同样的原文字幕和连续词范围；结果步骤独立翻译，不重新分句。翻译可选单条纯文本或批量 ID JSON，与模型及分句方式无关。温度、top_p、top_k、重复惩罚与输出上限可分步骤覆盖，留空沿用服务或模型默认值。各后端使用相同输入输出和校验，本地使用 GBNF 约束生成，云端校验后有限重试；硬约束不能保证翻译语义质量。样例预览不推理，真实请求预览使用实际输入及本地 tokenizer。

本地默认并发 2、云端 4，均可设置 1～8。分句块、前后参考、翻译批次、每行字数、最长时间及阅读速度目标由管线管理。模型可选择任意满足时长限制的连续词范围，不丢词或编造时码；标点、停顿和说话人不作为强制切点。本地预算不足时裁剪参考或按原词范围拆块；翻译批次可拆小，单条超限明确失败。每请求模型上下文默认 4096 token，较大分句块建议增加容量，输入 token 加输出预算须能放入上下文。最终分句时间冻结后，翻译、补译和重翻保持不变。每行字数限制最多两行，阅读速度是提示词目标。

模型由 Cuelify 自动启动的 `llama-server` 子进程运行，使用 Vulkan GPU 卸载。服务仅监听本机回环地址，自动分配端口，不弹出终端；首次使用加载模型，同配置后续请求复用已加载模型，关闭应用时结束进程。启动前不读取模型内容计算哈希或解析 GGUF 元数据；缓存通过文件路径、大小及修改时间区分模型版本。无需手动启动服务。点击「测试本地翻译」可验证模型运行，GPU 卸载详情见运行日志。模型、驱动或 GPU 不可用时明确报错，不回退 CPU-only。

## 数据与凭据

settings.json 使用 schema 5；schema 3/4 设置先备份再迁移，保留服务、模型和资产。旧联合管线改为模型分句后翻译，旧自定义联合提示词归档。项目 task.json 使用 schema 3；旧联合结果仅在原始词范围和时间可核实时导入分句与结果版本，保留原字幕和时码。已导入版本通过正常版本下拉访问，不能导入的原文件保留而不提供独立浏览入口，未完成任务从已有识别词重新分句。凭证、GGUF、运行包和旧缓存保留。

项目和媒体任务自动保存在 `%LOCALAPPDATA%\Cuelify\Projects\<项目ID>\`，项目列表扫描各目录的 `project.json`，媒体顺序由其中的 ID 列表保存。每个媒体有 `Media\<媒体ID>\task.json` 和独立的 `Results\<步骤>\<版本ID>\`；`workspace.json` 只保存最后打开的项目和媒体。重启可以查看和继续已有任务，异常退出留下的运行状态会恢复为已中断。媒体保存原始路径，不复制源视频；备份项目也需保留原媒体，独立分片文件仍可用于继续 ASR。历史成功缓存保留供校验复用，不自动重建为项目。

每步骤版本列表只显示匹配当前直接上游版本的历史。选择版本用于预览，点击「设为当前」才切换：下游自动选择最新匹配版本（包括失败），没有匹配时显示未开始。切换分句方式仍按同一条依赖链选择历史，查看历史不会改变 Tab。继续与失败重试使用本版本配置；重新执行使用当前设置生成新版本。重新分句创建新字幕，结果步骤重新执行或重新翻译均保留所选分句；重翻还可保留未选中的译文。版本和缓存不会自动清理。

非敏感配置和管线存放在 `%LOCALAPPDATA%\Cuelify\settings.json`，ASR、分句和翻译缓存分别位于 `Jobs`、`Pipelines`、`Translations`。步骤快照及缓存身份只包含本步骤的配置、实际输入、模型和输出契约，修改翻译规则不会使分句缓存失效。缓存含音频、原文和译文，分享前请检查内容。

首次使用时在密钥配置区域点击「设置主密码」，设置主密码，再填写 API 密钥；离开输入框时自动加密保存，点击「保存设置」也会保存密钥。每次启动需要解锁一次；语音识别、兼容服务和 DeepSeek 密钥分别保存到应用数据目录下的 `credentials.json`，使用 PBKDF2-SHA256 与 AES-256-GCM 加密，不依赖系统凭据存储，也不读取环境变量。主密码不保存，明文 Key 不进入普通配置或日志。

未设置或未解锁主密码、缺少所需密钥时，工作台会提示原因并禁用下一步或开始处理。本地翻译无需翻译服务密钥；只有需要执行 ASR 时才要求 ElevenLabs 密钥，单独 VAD 分片不需要服务密钥。手动锁定或退出会清除会话凭证，已有完整字幕仍可导出。可在「设置 → 常规」更换主密码或重置凭证；忘记主密码只能重置并重新填写密钥，普通设置和字幕缓存会保留。

## 从源码运行

安装 `global.json` 指定的 .NET 10 SDK，并准备 FFmpeg/ffprobe。在仓库根目录执行：

```powershell
dotnet restore Cuelify.slnx --locked-mode
dotnet run --project src/Cuelify.Desktop -c Release --no-restore
```

完整文档入口见 [文档索引](docs/README.md)。构建、测试、发布及资源来源见 [开发指南](docs/development.md)，运行问题见 [故障排查](docs/troubleshooting.md)。源码仓库中的后续 Agent 从 [AGENTS.md](AGENTS.md) 和 [Agent 文档索引](docs/agents/README.md) 开始。
