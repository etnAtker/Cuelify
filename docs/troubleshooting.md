# 故障排查

面向当前版本的使用与诊断，完整入口见[文档索引](README.md)。源码仓库中的验证结论和人工待验收项见[验证状态](agents/status.md)。

## 启动与文件

| 情况 | 处理 |
| --- | --- |
| 缺少 DLL 或无法启动 | 使用 Windows x64，保留完整发行目录及 `runtimes/win-x64/native`；不要只复制 exe。 |
| 找不到 ffmpeg/ffprobe | 加入启动进程 PATH，或在识别高级参数填写两个 exe 的绝对路径。 |
| 媒体无音轨/时长无效 | 由 ffprobe 实际识别，检查媒体是否有效且含音轨；标准识别流程要求媒体不超过 10 小时。 |
| 文件或模型不存在 | 检查媒体、GGUF 与 Silero 路径；发行包应包含 `Assets/silero_vad.onnx`。 |
| 保存 SRT 失败 | 使用独立 .srt 路径，不能覆盖输入；现有文件需确认覆盖。检查写权限及文件占用。 |

## API 与翻译

| 情况 | 处理 |
| --- | --- |
| 未填 Key / HTTP 401 | 先设置或解锁主密码，再在设置中填写对应服务密钥；当前工作台开始/继续前会检查对应凭据。底层完整缓存命中不会发送 HTTP，但不能据此跳过界面的凭据检查。认证失败不自动重试。 |
| HTTP 400 | 检查模型、地址、语言和高级参数；请求预览仅展示正文，不展示认证头。 |
| 旧版出现“分片识别数据或缓存校验失败” | Scribe 可能返回零时长词。更新后会保留文字，按设置中的“零时长字幕合并间隔”合并或独立显示；继续处理复用有效缓存，无需清空整个作业。其他无效或越界时码仍会报错。 |
| HTTP 429/5xx/网络失败 | 流程限次退避并尊重 Retry-After；成功结果保留，网络恢复后从缓存继续。重试可能重复计费。 |
| DeepSeek 思考参数无效 | 开启时 effort 为 low/high/max，top_p 若指定须为 0.95～1.0；关闭时不发送 effort/top_p。启用思考时不发送 temperature 或 penalty。只使用最终 content 作为译文。 |
| 高级 JSON 或提示词被拒绝 | 使用界面列出的白名单变量；批量模板保留 cues_json，单条保留 source_text。模板错误会标明名称：服务测试使用当前模型关联模板，保存设置检查整个已保存模板库；编辑区草稿需先保存再关联。JSON 不允许受控字段或嵌套凭据字段；不要将 Key 贴入模板。 |
| ID 不齐、空译文或部分失败 | 成功条目保留，错误条目单独补翻。可从缓存恢复或选中单条重翻；缺失译文不能导出完整 SRT。 |
| 修改设置后结果与新选项不一致 | 已完成任务继续使用原配置，可导出和单条重翻。保存设置用于新的处理；调整工作台选项后重新开始，才生成新配置的结果，ASR 缓存仍可复用。 |

请求预览含原文；缓存含音频、原文和译文，分享诊断信息前请检查内容。程序不保存服务错误正文或认证头到日志。

在日志页选择一条记录，或用 Ctrl/Shift 选择多条，再点击“复制所选日志”、使用右键菜单或按 Ctrl+C；Ctrl+A 可全选。多行调用栈会完整复制。

第二步的源语言同时控制识别和翻译，选择中文名称即可；应用会映射为 ElevenLabs 接受的 ISO 639-1/639-3 语言代码。默认自动识别，不再另填地区或识别代码。默认语言集中在设置的常规页。

## 本地 Vulkan

| 情况 | 处理 |
| --- | --- |
| llama.cpp 无法加载模型 | 查看日志中的 llama.cpp 加载错误，检查文件是否完整、运行包是否支持该模型、显存是否足够；必要时重新选择或下载模型。手动选择和启动前不校验模型身份、内容哈希或 GGUF 元数据，由 llama.cpp 判断可否加载。 |
| 下载中断或网络失败 | 检查网络能否访问 Hugging Face，再点击「下载模型」继续。可续传片段保留；官方文件更新后会重新下载，原正式模型在校验完成前保留。 |
| NativeLibrary / VulkanOffload | 点击「下载 llama.cpp」，或重新选择完整 Windows x64 Vulkan 包中的 llama-server.exe；保留配套 DLL，检查显卡驱动，再测试本地翻译。 |
| ServerMissing / ServerIncompatible | 在设置中下载当前运行包或指定兼容的 llama-server.exe，不能选择 llama-cli.exe。保存后测试本地翻译。 |
| 运行包下载失败 | 检查 GitHub 访问、设置目录写权限和可用空间，再点击「下载 llama.cpp」继续。取消保留片段；校验失败或解压失败不覆盖旧版本。 |
| 本地服务退出或容量不足 | 降低本地并发或每条上下文长度，检查运行包版本和显存，再测试本地翻译。服务由应用自动启动，不必手动配置端口。 |
| 显存不足 | 先降低本地并发数，再根据实际显存调低正数 GPU layers/context size；不能设置 0 或改为 CPU-only。 |
| Token 预算或非 EOS | 参考内容会按实际 token 预算裁剪；批量仍超限会拆小批次；单条及指令仍超限时调大上下文长度或缩短模板。调整最大输出长度以避免生成截断，截断结果不会缓存。 |
| 语义不佳 | 审阅称呼、专有名词和上下文，修改简短模板后定向重翻；结构对齐不代表语义完全正确。 |

官方 Vulkan 运行包包含 CPU 运算 DLL，这是上游依赖。应用强制选择 Vulkan 设备，实际验证检查本次服务的设备、GPU 模型缓冲、非零 layer offload 和真实生成；完整翻译缓存命中不会发送生成请求。运行包按版本保留，删除旧版本前确认已有任务不再引用它。

## 配置、缓存与取消

旧配置不迁移，首次加载备份为同目录 settings.previous-*.json 并重建默认设置，需重新配置服务和模型。未来版本或损坏 JSON 不自动覆盖；模型、运行包、缓存和独立凭证文件保留。

用户目录为 `%LOCALAPPDATA%\Cuelify`：`settings.json` 保存非敏感参数/提示词，`Jobs` 保存识别缓存，`Translations` 保存译文缓存。密钥在 `credentials.json` 中通过主密码加密保存，每次启动需要解锁；不读取环境变量。

- JSON 损坏会明确报错。先备份并检查对应文件，恢复备份或有意删除损坏条目；不要直接清空成功结果导致重新付费。
- 作业锁占用时等待原进程退出。同一输入作业只能由一个进程处理；留在磁盘的锁文件不是占用证据，排他性来自文件句柄。
- 取消会传递给 HTTP、FFmpeg 与本地生成；成功结果保留，再次开始复用缓存。关闭窗口等待资源释放。
- 定向重翻会失效选中 ID 的旧译文；失败或取消后该 ID 仍需重新完成，未选中译文保留。
- 无法保存设置时检查用户目录写权限；保存和任务在初始化完成后启用。

## 主密码与密钥

- 下一步置灰：按附近提示设置或解锁主密码，并填写 ElevenLabs 密钥。第二步开始处理还需要所选云端翻译服务的密钥；本地不需要翻译密钥。
- 主密码不正确或文件损坏：先检查输入，保留文件；无法恢复时在设置的常规页重置凭证并重新填写密钥，普通设置及字幕缓存不受影响。
- 凭证被其他窗口修改：锁定后重新解锁，避免用旧会话覆盖新密钥。修改凭证期间的锁文件占用不代表文件损坏。
- 兼容服务地址变化：确认已有密钥用于新地址，或重新填写密钥，再分别保存密钥和服务设置。
- 锁定后仍可查看和导出完整字幕；重新处理或云端重翻前需要解锁。
