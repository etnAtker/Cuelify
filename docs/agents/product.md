# 产品范围与行为契约

本文件承接原 MVP 的有效范围，并纳入之后已批准的界面和状态变更。这里的限制是产品约束；可调默认值和依赖版本分别以源码与[开发指南](../development.md)为准。改变范围须获得用户明确批准，并更新[决策记录](decisions.md)。

## 产品目的

Cuelify 的长期目标是跨平台，当前发行与正式验收仍为 Windows x64。本轮凭证层不依赖平台专用安全存储，其他平台构建与发行适配另行规划。Cuelify 是轻量字幕桌面工具：项目中的本地音视频文件，经 FFmpeg 音频处理、Silero VAD 分片、ElevenLabs Scribe 识别及 LLM 翻译，导出 UTF-8 译文 SRT。正式验收环境为 Windows 11 x64，主要开发环境为 Rider。

## 必须保留的功能

- 项目可添加多个本地媒体，项目内按保存顺序执行，也可独立操作一个媒体；媒体内部保留分片/请求并发。选择或拖放文件，由 ffprobe 实际确认时长和音轨，不仅按扩展名推断可用性。
- VAD 辅助选择合理切点；支持上传大小限制、片段重叠、词级时码转换及边界去重。
- ElevenLabs Scribe ASR，可自动识别或指定语言；支持成功分片缓存、失败分片重试及取消。
- 三条翻译路径：OpenAI-compatible Chat Completions、DeepSeek 官方 API、应用管理的本地 llama.cpp llama-server + Vulkan。
- 字幕管线库独立管理，两个内置只读流程为程序分句后翻译、模型分句后翻译，默认使用模型分句；自定义可增删改查/复制。固定分片、识别词、分句、结果四步，结果只消费分句，不直接消费识别词。模型不关联默认管线；管线步骤配置默认模型，媒体步骤可覆盖，无有效引用时必须选择模型，不自动选择列表首项。程序和模型分句输出同构 SubtitlePipelineResult，分句不包含译文。单条/批量属性独立归翻译步骤。阶段提示词、采样、分块、上下文与显示目标归管线，保留草稿切换、只读内置、样例和真实请求预览。
- 云端服务支持地址、模型名、可选生成参数、超时、并发、重试与校验后的附加 JSON。参数支持情况取决于提供商，不能假设所有兼容接口接受同一思考开关。
- 本地预置官方 Hy-MT2-1.8B Q6_K、Hy-MT2-7B Q4_K_M、Index-Translate-9B Q4_K_M。下载动态读取官方当前文件信息，不冻结远端版本、文件名、大小或 SHA；模型及默认路径位于配置文件同级目录，来源见根目录 README。
- 手动选择和运行前只检查模型路径、可读性及文件版本，不读取模型内容计算哈希或解析 GGUF 元数据，不要求手动文件与预设身份匹配。可否加载由 llama.cpp 判断，保留其加载错误日志；下载流程仍做完整性校验。同配置、同文件版本且服务可用时直接复用已加载模型。
- 本地运行包动态查询官方 Windows x64 Vulkan 资产（包括滚动预发布），下载与安全解压到配置目录的 `llama.cpp/`，支持取消、续传和手动指定 `llama-server.exe`；不同版本保留，更新不覆盖任务快照引用的运行包。
- 所有后端均支持全部管线以及翻译步骤的单条纯文本/批量 ID JSON，批次属性与模型解耦。并发按请求计算，均可调 1～8，本地默认 2、线上默认 4。每个本地请求独立预算；分句容量不足按合法候选拆块，翻译容量不足拆批；最小请求仍超限明确失败。同波次翻译前文取稳定快照。
- 显示真实阶段、原译文对照、日志和可执行的错误建议；支持继续处理、单条/多选重翻和完整译文导出。
- 项目列表、项目工作台、设置和日志独立；项目详情左侧媒体、右侧按实际步骤展示结果，详见 [UI 规约](ui-guidelines.md)。

## 固定技术边界

| 领域 | 约束 |
| --- | --- |
| 应用 | .NET 10 / C#、Avalonia、CommunityToolkit.Mvvm；原生桌面窗口 |
| 平台 | 当前发行与验收为 Windows x64；长期目标跨平台，其他平台适配另行规划 |
| 媒体 | `ffmpeg.exe` / `ffprobe.exe` 经 `ICommandRunner` 和 Process 调用；不接原生 FFmpeg C API |
| VAD | Silero ONNX + ONNX Runtime CPU；CPU 用于 VAD不等于允许 CPU-only LLM |
| 本地翻译 | 应用管理的 llama-server 子进程 + Vulkan；禁用 CUDA、CPU-only 回退和自动后端回退 |
| 持久化 | JSON 配置与缓存、原子写入；配置 schema 5，schema 3/4 备份后迁移，更早设置备份后重建；task schema 3 备份迁移旧联合结果；模型/运行包/缓存及独立凭证保留，不引入数据库或通用插件架构 |
| 发行 | `win-x64` self-contained 目录；Silero 随包，FFmpeg 由用户准备，llama.cpp 运行包和 GGUF 在应用中下载或由用户选择 |

不采用 Electron、WebView 界面或独立部署的 Web 服务。本地推理仅使用应用管理的 llama-server 子进程，监听 127.0.0.1、自动分配端口并随应用结束；不连接外部已运行的模型服务，不采用 Ollama、LM Studio 或 llama-cli 作为正式实现。

## 时间轴、翻译与导出契约

1. VAD 只寻找切点，不删除静音或把语音拼接为紧凑音轨。分片必须连续覆盖原音频；只有必要的强制切分引入短重叠。
   ASR 返回零时长词时保留文字和原始词时码：在可配置容差内并入时间更近的同说话人相邻有效文本（等距优先后词），以时间范围并集构建字幕；没有可合并文本时，作为持续该容差时长的独立字幕。同一时刻的连续孤立文字组成一句。容差默认 500 毫秒，可在识别高级设置中调整为 1～7000 毫秒。
2. ASR 全局词时间为片段起点加服务返回的局部时间。边界去重必须结合时间与文本，不能删掉发生在不同时间的重复台词。
3. 原始 ASR 词文本、顺序及其时码不可修改。程序分句使用 CueBuilder，模型分句选择连续词范围末 ID，程序验证连续词范围、完整覆盖及用户配置的最长时间，不按标点、助词、说话人或固定停顿阈值排除词边界，再生成原文 cue。重叠或同起点文字可合并，显示可在可用静音中延长。分句版本的 ID、数量、顺序和时间固定，结果步骤仅生成译文，补译和重翻不重新分句；独立重新分句创建新分句版本。
4. Core 定义提供商无关的 GenerationOutputContract。模型分句输出 ends JSON，禁止漏词、重复、重排及非法路径；翻译批量输出 cueId -> translatedText JSON，单条输出纯文本。输入输出和业务校验与模型、提供商无关；本地适配器从相同契约编译 GBNF，云端验收并有限重试，不声称兼容服务或 DeepSeek strict 已保证硬约束。
5. 校验缺失、空白、非法控制字符、输出结构、ID 对齐和最大两行字数，保留有效译文并有限补翻。不以原译文相同判定失败，失败不能用原文填补。硬约束不保证语义对齐、否定或专名正确，阅读速度也是提示词目标；内容质量需单独评估。
6. 完整译文 SRT 要求所有条目有效。当前界面不提供跳过失败条目或以原文填补的导出方式；原文 SRT 可作内部处理中间产物，不新增对外输出选项。
7. ASR、分句、翻译缓存分开；成功块逐块保存，取消后可复用。身份包括本步实际输入、配置、模型和输出契约，不包含其他步骤参数或密钥。仅修改翻译提示词、批次或显示字数不使分句缓存失效。各阶段真实请求与缓存分别计数。
8. 已完成结果绑定版本配置快照。继续与失败重试沿用快照；重新执行使用当前步骤模型与设置创建新版本。结果步骤单独提供重新翻译（全部/所选），固定原分句、cue ID、顺序和时码，记录被重翻的结果版本；未选中有效译文保留。

## 项目与阶段持久化

项目名可修改，目录使用稳定 GUID；项目清单保存媒体 ID 和顺序，原媒体保存绝对路径引用，不默认复制。数据根沿用 ConfigurationStore.Root，默认 `%LOCALAPPDATA%\Cuelify`；Projects 中各 project.json 为项目列表事实来源，workspace.json 只记录最后选择。项目 schema 1、task schema 3、配置 schema 5。旧 task 先备份并补齐明确上游引用，旧联合结果只有在连续范围、原文与词时间可核实时才导入分句/结果版本，固定旧 cue 与时码。旧文件保留，能导入的版本通过正常步骤下拉查看；不能核实的结果不提供独立浏览入口，也不能设为当前；未完成联合任务不能继续旧算法，复用已有分片和识别词重新分句。旧成功缓存保留并按身份校验。

分片、识别词、分句及结果分别维护同构版本描述、状态、配置/模型快照、直接上游步骤与版本 ID、结果路径和失败单元。状态包括未开始、运行、部分失败、失败、取消、中断、完成；需更新与结果不可用独立记录。JSON 原子写入，项目排他锁保护执行和恢复；重启不自动请求服务，运行状态转为已中断。

每步骤首次执行捕获直接上游步骤与版本 ID，以及仅属于本步骤的配置和模型快照。继续复用本版本成功单元；失败重试只处理记录的失败单元并使用固定快照；重新执行建立新版本，使用当前上游及步骤设置。内容哈希只用于缓存，不决定版本依赖。

版本下拉只预览，独立「设为当前」按钮提交。上游切换或管线切换时，沿固定分片→识别词→分句→结果链，按直接上游 ID 筛选，选择创建时间最新版本（包括失败），无匹配则显示未开始；历史保留，失败上游不能执行下游，不自动运行。程序和模型分句共享历史版本目录。预览不改变 Tab，完整历史结果可导出。旧联合档案不提供专用界面入口，不混入当前依赖候选。

结果步骤记录生成或重翻方式，始终依赖分句版本；重新生成结果与重翻均不能调用分句引擎。重翻保留 ID、数量和时间，记录基础结果版本，未选中的有效译文保留。

项目内顺序处理遇到单个媒体普通失败继续后续媒体，取消或缺失凭证停止；不同时运行多个媒体。媒体可软移出项目并撤销，保留文件；源文件移动后可重新定位。本期不提供项目删除、跨项目任务移动或自动清理历史版本。

## 凭据、取消和费用

API Key 不进入普通配置 JSON、缓存键、日志、认证正文预览或命令行参数。凭证通过主密码加密保存到独立文件，每次启动默认锁定；不读取环境变量。按操作检查凭据：分片不需服务密钥，识别词需 ElevenLabs，云端分句/结果需对应翻译密钥，本地模型不需翻译密钥。已有结果的查看和导出不要求解锁。

ElevenLabs、兼容 API、DeepSeek 密钥隔离；兼容服务密钥关联地址，地址变化后需确认或重新填写。输入框失焦默认加密保存，保存设置也保存密钥；加载/锁定清空输入不保存。模型列表包含预置 DeepSeek、三个本地模型与已保存服务档案，不按密钥状态增删，保存服务设置立即刷新。锁定或退出清除会话凭证；处理中禁用凭证修改、锁定与重置。更换主密码验证旧密码并原子重加密；忘记密码只能确认重置凭证，保留普通设置及缓存。损坏、不支持或不可读的文件不自动覆盖。

ASR 上传音频，云端翻译发送字幕及上下文；连接测试、重试和重翻所选字幕可能计费。以自然文案在相关操作附近说明。设置错误、缺少凭据、无法读取文件等必须先校验，不能通过反复请求掩盖配置问题。

取消应传递到 HTTP、FFmpeg 进程树和本地推理。成功结果保留；关闭窗口等待任务结束及进程、上下文、权重等资源释放。界面不能因切换页面而取消或重建任务。

## 本期范围外

不添加跨项目并行或通用队列、在线视频下载、内置播放器、波形或时间轴编辑、完整字幕编辑器、TTS/配音、烧录、VTT/ASS、额外 ASR 提供商、术语或角色管理界面、AI 校对、任务云同步、常驻后台守护进程、无用户操作的自动模型或运行包下载或任意 GGUF 管理。本地模型范围限于上述三个预设；Linux、macOS、ARM64、CUDA 或 CPU-only 本地推理不在当前适配范围。

## 完成与验收

自动化测试、真实服务联调、真实 GPU 推理、原生 GUI 自动化和人工验收是不同证据。完整验收需真实媒体端到端运行、三条翻译路径分别验证、非零 Vulkan layer offload 与实际生成、正确时码/SRT、取消与恢复，以及独立无 SDK 的 Windows 11 x64 和 GUI 人工检查。当前进度及尚未覆盖的项目见[验证状态](status.md)，不能用旧版本或模拟结果宣称全部完成。
