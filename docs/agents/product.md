# 产品范围与行为契约

本文件承接原 MVP 的有效范围，并纳入之后已批准的界面和状态变更。这里的限制是产品约束；可调默认值和依赖版本分别以源码与[开发指南](../development.md)为准。改变范围须获得用户明确批准，并更新[决策记录](decisions.md)。

## 产品目的

Cuelify 的长期目标是跨平台，当前发行与正式验收仍为 Windows x64。本轮凭证层不依赖平台专用安全存储，其他平台构建与发行适配另行规划。Cuelify 是轻量字幕桌面工具：一个本地音视频文件，经 FFmpeg 音频处理、Silero VAD 分片、ElevenLabs Scribe 识别及 LLM 翻译，导出 UTF-8 译文 SRT。正式验收环境为 Windows 11 x64，主要开发环境为 Rider。

## 必须保留的功能

- 一次处理一个本地媒体。选择或拖放文件，由 ffprobe 实际确认时长和音轨，不仅按扩展名推断可用性。
- VAD 辅助选择合理切点；支持上传大小限制、片段重叠、词级时码转换及边界去重。
- ElevenLabs Scribe ASR，可自动识别或指定语言；支持成功分片缓存、失败分片重试及取消。
- 三条翻译路径：OpenAI-compatible Chat Completions、DeepSeek 官方 API、应用管理的本地 llama.cpp llama-server + Vulkan。
- 提示词库独立管理，内置通用字幕批量、简单单条、上下文单条三个只读模板；自定义模板支持新建、搜索、复制、编辑和删除。模型关联模板 ID，默认线上批量、1.8B 简单单条、7B 上下文单条，允许改关联并共用模板；删除已引用模板前说明相关模型将恢复各自默认提示词，确认后原子保存；未保存新模板可直接确认丢弃草稿。提供变量说明、无推理的样例预览及真实任务请求预览。
- 云端服务支持地址、模型名、可选生成参数、超时、并发、重试与校验后的附加 JSON。参数支持情况取决于提供商，不能假设所有兼容接口接受同一思考开关。
- 本地模型预置官方 Hy-MT2-1.8B Q6_K、Hy-MT2-7B Q4_K_M。下载和默认路径在配置文件同级目录；下载动态读取官方当前文件信息与可用校验值，不固定远端版本、文件名、大小或 SHA-256。来源见根目录 [README](../../README.md#本地模型)。
- 手动选择和运行前只检查模型路径、可读性及文件版本，不读取模型内容计算哈希或解析 GGUF 元数据，不要求手动文件与预设身份匹配。可否加载由 llama.cpp 判断，保留其加载错误日志；下载流程仍做完整性校验。同配置、同文件版本且服务可用时直接复用已加载模型。
- 本地运行包动态查询官方 Windows x64 Vulkan 资产（包括滚动预发布），下载与安全解压到配置目录的 `llama.cpp/`，支持取消、续传和手动指定 `llama-server.exe`；不同版本保留，更新不覆盖任务快照引用的运行包。
- 所有翻译后端均支持单条纯文本与批量 ID JSON；模式、每批条数/字符上限归提示词所有，与线上/本地模型解耦。并发按请求计算，均可调 1～8，本地默认 2、线上默认 4。每个本地请求独立使用配置的上下文预算；参考裁剪后仍超限则拆小批次，单条仍超限时报错。同波次前文取波次开始时的稳定快照。
- 显示真实阶段、原译文对照、日志和可执行的错误建议；支持继续处理、单条/多选重翻和完整译文导出。
- 工作台、设置、日志独立；工作台按选择文件、翻译选项、生成字幕三步推进，详见 [UI 规约](ui-guidelines.md)。

## 固定技术边界

| 领域 | 约束 |
| --- | --- |
| 应用 | .NET 10 / C#、Avalonia、CommunityToolkit.Mvvm；原生桌面窗口 |
| 平台 | 当前发行与验收为 Windows x64；长期目标跨平台，其他平台适配另行规划 |
| 媒体 | `ffmpeg.exe` / `ffprobe.exe` 经 `ICommandRunner` 和 Process 调用；不接原生 FFmpeg C API |
| VAD | Silero ONNX + ONNX Runtime CPU；CPU 用于 VAD不等于允许 CPU-only LLM |
| 本地翻译 | 应用管理的 llama-server 子进程 + Vulkan；禁用 CUDA、CPU-only 回退和自动后端回退 |
| 持久化 | JSON 配置与缓存、原子写入；schema 2 不迁移旧设置，备份后重建，模型/运行包/缓存及独立凭证文件保留；不引入数据库或通用插件架构 |
| 发行 | `win-x64` self-contained 目录；Silero 随包，FFmpeg 由用户准备，llama.cpp 运行包和 GGUF 在应用中下载或由用户选择 |

不采用 Electron、WebView 界面或独立部署的 Web 服务。本地推理仅使用应用管理的 llama-server 子进程，监听 127.0.0.1、自动分配端口并随应用结束；不连接外部已运行的模型服务，不采用 Ollama、LM Studio 或 llama-cli 作为正式实现。

## 时间轴、翻译与导出契约

1. VAD 只寻找切点，不删除静音或把语音拼接为紧凑音轨。分片必须连续覆盖原音频；只有必要的强制切分引入短重叠。
   ASR 返回零时长词时保留文字和原始词时码：在可配置容差内并入时间更近的同说话人相邻有效文本（等距优先后词），以时间范围并集构建字幕；没有可合并文本时，作为持续该容差时长的独立字幕。同一时刻的连续孤立文字组成一句。容差默认 500 毫秒，可在识别高级设置中调整为 1～7000 毫秒。
2. ASR 全局词时间为片段起点加服务返回的局部时间。边界去重必须结合时间与文本，不能删掉发生在不同时间的重复台词。
3. `SubtitleCue` 的 ID、数量、顺序、起止时间由识别流程确定。翻译只补充译文，不重新推断或重写字幕时间。
4. 批量模板使用 `cueId -> translatedText` JSON 对齐；单条模板输出纯文本，由应用关联原 ID。批量降为单条补翻仍保持同一模板和 JSON 协议。上下文只供理解，不属于需重新输出的字幕。
5. 校验缺失、空白、非法控制字符、输出结构和 ID 对齐，保留有效部分并有限补翻。不以译文与原文相同判定失败，服务实际返回的相同文字可接受；失败时仍不能用原文静默填补译文。
6. 完整译文 SRT 要求所有条目有效。当前界面不提供跳过失败条目或以原文填补的导出方式；原文 SRT 可作内部处理中间产物，不新增对外输出选项。
7. 成功的 ASR 与翻译缓存分开。只改变翻译配置应复用符合原识别配置的 ASR；缓存命中和真实请求必须分别计数。
8. 已完成结果绑定任务启动时的配置快照。后续全局设置修改不影响其导出、请求预览及单条/多选重翻；重新开始处理才应用新的已保存配置和本次任务选项。重翻只替换所选字幕的结果，保留未选中条目及所有原时码。

## 凭据、取消和费用

API Key 不进入普通配置 JSON、缓存键、日志、认证正文预览或命令行参数。凭证通过一个主密码加密保存到独立文件，采用 PBKDF2-SHA256 与 AES-256-GCM，不依赖操作系统账户或安全存储，不读取环境变量。主密码不保存，每次启动默认锁定；未设置主密码、未解锁或缺少对应密钥时禁用流程推进。第一步需要 ElevenLabs 密钥，第二步还需所选云端翻译密钥，本地翻译不需要翻译密钥。已完成结果的查看与导出不要求解锁。

ElevenLabs、兼容 API、DeepSeek 密钥隔离；兼容服务密钥关联地址，地址变化后需确认或重新填写。锁定或退出清除会话凭证；处理中禁用凭证修改、锁定与重置。更换主密码验证旧密码并原子重加密；忘记密码只能确认重置凭证，保留普通设置及缓存。损坏、不支持或不可读的文件不自动覆盖。

ASR 上传音频，云端翻译发送字幕及上下文；连接测试、重试和重翻所选字幕可能计费。以自然文案在相关操作附近说明。设置错误、缺少凭据、无法读取文件等必须先校验，不能通过反复请求掩盖配置问题。

取消应传递到 HTTP、FFmpeg 进程树和本地推理。成功结果保留；关闭窗口等待任务结束及进程、上下文、权重等资源释放。界面不能因切换页面而取消或重建任务。

## 本期范围外

不添加多文件队列、在线视频下载、内置播放器、波形或时间轴编辑、完整字幕编辑器、TTS/配音、烧录、VTT/ASS、额外 ASR 提供商、术语或角色管理界面、AI 校对、任务云同步、常驻后台守护进程、无用户操作的自动模型或运行包下载或任意 GGUF 管理。本地模型范围限于上述两个预设；Linux、macOS、ARM64、CUDA 或 CPU-only 本地推理不在当前适配范围。

## 完成与验收

自动化测试、真实服务联调、真实 GPU 推理、原生 GUI 自动化和人工验收是不同证据。完整验收需真实媒体端到端运行、三条翻译路径分别验证、非零 Vulkan layer offload 与实际生成、正确时码/SRT、取消与恢复，以及独立无 SDK 的 Windows 11 x64 和 GUI 人工检查。当前进度及尚未覆盖的项目见[验证状态](status.md)，不能用旧版本或模拟结果宣称全部完成。
